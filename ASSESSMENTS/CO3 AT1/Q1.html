init()

The init() method is called only once when the servlet is initialized. It is used for initialization tasks such as loading configuration or database connections.

service()

The service() method receives client requests and sends responses. It determines whether the request should be processed by doGet() or doPost().

destroy()

The destroy() method is called before the servlet is removed from service. It is used to release resources.

Servlet Architecture

Student Browser → HTML Form → HTTP GET / POST → Servlet Container → StudentServlet → Processing → HTTP Response → Browser

GET vs POST

GET POST
Data is sent through the URL. Data is sent through the request body.
Suitable for retrieving data. Suitable for submitting data.
Less suitable for sensitive information. More appropriate for sensitive form data.
