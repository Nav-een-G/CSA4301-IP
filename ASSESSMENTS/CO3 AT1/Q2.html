HttpSession

HttpSession is a server-side session management mechanism provided by Java Servlets. After a successful login, the server creates a session using request.getSession() and stores user information using setAttribute().


Example: 

HttpSession session = request.getSession();

session.setAttribute("username", username);

String user =
    (String) session.getAttribute("username");

Cookies

Cookies are small pieces of information stored in the user's browser. A servlet can create a cookie and send it to the browser. The browser sends the cookie back with subsequent requests. 


Cookie cookie =
    new Cookie("username", username);

cookie.setMaxAge(3600);

response.addCookie(cookie);

Session vs Cookies

HttpSession Cookies
Session information is maintained on the server. Cookie information is stored in the browser.
More suitable for maintaining authenticated user state. Useful for preferences and user identification.
Session ID identifies the user. Cookie name and value identify stored information.
Session can expire after inactivity. Cookie can have a specified expiry time.
Sensitive information should remain on the server. Sensitive information should not be directly stored in cookies.

Servlet Session Management Process

  1. User enters username and password.
  2. Login request is sent to the servlet.
  3. Servlet validates the credentials.
  4. HttpSession is created.
  5. Username is stored in the session.
  6. A session ID is maintained between the browser and server.
  7. The user can access multiple pages without logging in again.
  8. The session is destroyed when the user logs out or the session expires.
