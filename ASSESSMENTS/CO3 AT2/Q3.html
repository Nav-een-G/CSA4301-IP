JDBC Architecture

Web Browser
↓
Java Servlet
↓
JDBC API
↓
JDBC Driver
↓
MySQL Database

Steps for Database Connectivity

  1. Load JDBC Driver: Load the MySQL JDBC driver.
  2. Establish Connection: Connect the Java application to the database.
  3. Create Statement: Create a Statement or PreparedStatement.
  4. Execute SQL Query: Execute INSERT or SELECT queries.
  5. Process Result: Retrieve data using ResultSet.
  6. Close Resources: Close database connections and statements.
  7. Handle Exceptions: Handle database errors using SQLException.

SQL Queries

Insert Query: 
INSERT INTO products
(name, price, quantity)
VALUES (?, ?, ?);
Retrieve Query: 
SELECT id, name, price, quantity
FROM products;

Exception Handling

ClassNotFoundException: Occurs when the JDBC driver cannot be found.

SQLException: Handles database connection and SQL errors.

NumberFormatException: Handles invalid numeric input such as price or quantity.

Try-with-resources: Automatically closes database resources.
